# DS-01 — Tokens y consola estable

Inicio: 2026-10-06, después de NLP-01. Estado: parcial para aceptación visual; tokens/layout implementados y contraste medido.

Alcance: CSS/JS extraídos a static, tokens semánticos en raíz heredados por controles, superficies opacas, texto/candidatos/alertas de alto contraste y cifras tabulares. Vista dual desktop/apilada móvil, espacio de video/estados reservado, foco visible y zoom permitido, movimiento reducido. Script externo permite retirar unsafe-inline de script-src; estilos inline heredados conservan deuda parcial UX-SEC-01.

Validación: `python -m scripts.check_contrast` genera ratios de texto sobre surface ≥7:1 (incluye texto oscuro sobre accent por simetría). No se afirma AAA global. El catálogo CSS funciona como tokens de runtime; exportación DTCG formal queda pendiente de validar contra [formato 2025.10](https://www.designtokens.org/tr/2025.10/format/), sin fingir que un JSON propio es estándar W3C.

Límite: CLS, lector de pantalla y operación visual móvil no medidos en navegador en esta tarea; no se marca aceptación DS-01 completa. UX-01 prepara todos los estados; QA-01 debe medir CLS ≤0.1 y accesibilidad aplicable. No se crean nuevas librerías o frameworks.
