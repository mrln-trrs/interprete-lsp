# HW-01 — Salida Arduino opcional (protocolo V1)

Inicio: 2026-10-21, sobre trabajo local sin commit. Estado: Done para software; prueba en placa real pendiente. Arduino sigue siendo opcional y viene desactivado: sin `--serial-port` no se abre ningún puerto.

Alcance: `src/hardware/serial_controller.py` implementa el protocolo de [SERIAL-PROTOCOL](../hardware/SERIAL-PROTOCOL.md): codificación y validación de tramas, `FirmwareSimulator` (referencia ejecutable del firmware) y `SerialController` con cola de una salida (la más reciente gana), hilo propio, un reintento solo tras timeout, handshake PING, degradación a Partial ante fallas y reconexión acotada que descarta salidas antiguas. `arduino/lsp_display_controller/lsp_display_controller.ino` implementa la misma máquina de estados con buffer fijo de 64 bytes (sin `String`), vaciado tras overflow y deduplicación por SEQ; el efecto actual es el LED integrado porque la pantalla no está elegida. `TranslationPipeline` acepta `on_gloss` y solo envía glosas validadas del vocabulario base (0–8); números, letras y meses no viajan en V1. `web_server.py --serial-port COM3` conecta, informa el estado en el preflight y sigue sin hardware si el puerto no responde.

Validación: `tests/test_hardware.py`, 15 pruebas PASS: HW-T01–T07 sobre el simulador, controlador con fallas inyectadas (timeout, reintento, desconexión, puerto ausente, hilo sin bloqueo), pyserial real sobre un puerto virtual pty y paridad del `.ino` compilado con g++ en el host frente al simulador en 28 tramas límite. El firmware compila para Arduino Uno con arduino-cli 1.1.1 y arduino:avr 1.8.8, sin advertencias propias: 4532 bytes de flash (14 %) y 346 bytes de RAM (16 %). Prueba de sistema: servidor real con `--serial-port` sobre pty y simulador, handshake y preflight «conectado» ([evidencia](../quality/evidence/system-check-2026-10-21.json)).

Límite: simulación y compilación no certifican la integración física; faltan placa real, cable, tiempos a 9600 baudios en hardware y elección de pantalla (HW-DEBT-01). El protocolo no tiene autenticación ni CRC: usar solo enlace USB controlado.
